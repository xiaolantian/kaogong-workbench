# 考公Q版工作台 设计文档

> 日期：2026-08-11
> 状态：已确认

## 产品概述

一款Q版卡通风格的拟真桌面工作台Web应用，专注服务公务员考试备考人群。
拟真桌面 + 可拖拽弹窗 + 吉祥物驱动的学习体验，覆盖备考全流程。

## 技术栈

| 层级 | 选型 | 说明 |
|------|------|------|
| 前端框架 | React 18 + TypeScript + Vite | 现代标准组合 |
| 状态管理 | Zustand | 轻量，适合分散工作台状态 |
| 路由 | React Router 6 | 各模块独立路由 |
| UI框架 | 无（全自绘） | Q版风格需要高度定制 |
| CSS | TailwindCSS + 手写CSS动画 | 工具类 + 自定义动画 |
| 动画 | Framer Motion | 弹性缓动，60fps流畅 |
| 桌面端 | Tauri 2.0 | Rust内核，包体小，性能好 |
| 移动端 | Capacitor | 同一份前端代码打包APK |
| 本地存储 | SQLite (Tauri) / IndexedDB (Web) | 离线可用 |
| 吉祥物 | 自绘SVG + CSS动画 | 方便表情/动作切换 |

## 拟真桌面系统

### 桌面层
- 全屏壁纸背景，支持主题切换
- 底部Dock栏（macOS风格，Q版图标排列）
- 左上角时钟小部件（吉祥物头像 + 实时时间）
- 桌面图标支持拖拽重新排列

### 窗口系统
- 每个模块以弹窗形式打开
- 支持拖拽、缩放、最小化到Dock
- 窗口边框Q版装饰（圆角 + 卡通元素）
- 多窗口自由排列

### 图标系统

| 模块 | 图标名称 | 形象 |
|------|---------|------|
| 专注时刻 | 专注时刻 | 戴学士帽的小猫看书 |
| 知识卡卡 | 知识卡卡 | 会翻动的卡通书 |
| 今日计划 | 今日计划 | 戴眼镜的Q版小人拿清单 |
| 题题大作战 | 题题大作战 | 游戏闯关风格图标 |
| 新闻早报 | 新闻早报 | Q版播报员拿喇叭 |

### 吉祥物
- **形象**：Q版小猫，戴学士帽
- **实现**：SVG绘制 + CSS Keyframes动画
- **表情系统**：
  - 专注（戴帽看书）
  - 困倦（打瞌睡，计时中）
  - 开心（答对题/完成计划）
  - 挫败（答错题，挠头）
  - 庆祝（达成streak）
- **状态联动**：学习streak越长，小猫越精神

## 功能模块

### 模块一：专注时刻（番茄钟）
- 可自定义学习/休息时长（默认25/5分钟）
- 小猫状态动画随计时变化
- 白噪音背景（雨声、咖啡馆、图书馆）
- 每日/每周专注时长统计图表
- 完成目标后庆祝动画 + Dock烟花

### 模块二：知识卡卡（SRS记忆卡片）
- 内置考公高频知识点模板（行政法、时政常识、申论金句）
- 支持导入 Anki 包 (.apkg) 和手动创建
- SM-2 间隔重复算法自动安排复习
- 翻卡片动画，正/误不同吉祥物反馈
- 遗忘曲线可视化

### 模块三：今日计划（学习看板）
- 三列看板：今日任务 / 本周目标 / 已完成
- 拖拽调整优先级
- 每日打卡streak系统
- 进度环 + 完成率统计
- 完成时有打勾动画 + 小猫欢呼

### 模块四：题题大作战（刷题器）
- 内置行测高频题型（言语理解、数量关系、判断推理、资料分析、常识）
- 支持导入Excel/JSON题库
- 答题计时压力感（倒计时条 + 小猫紧张表情）
- 自动计分 + 错题本
- 错题自动同步生成知识卡片进入SRS队列
- 答对/答错不同动画反馈

### 模块五：新闻早报（每日时政）
- 内置时政热点库（可更新）
- 用户可手动添加时政笔记
- 每天弹窗推送3-5条重要时政（Tauri桌面通知）
- 时政关联考点标注

## 数据模型

| 表名 | 用途 |
|------|------|
| study_plans | 学习计划/任务 |
| study_sessions | 专注时长记录 |
| flashcards | 知识卡片（含SRS元数据） |
| quiz_questions | 题库 |
| quiz_attempts | 刷题记录 |
| wrong_book | 错题本 |
| news_notes | 时政笔记 |
| user_settings | 用户设置（壁纸、主题等） |
| desktop_layout | 桌面图标位置 |

### 关键数据流
- 刷题错题 → 错题本 → 自动生成知识卡片 → SRS复习队列
- 专注时长 → 累计统计 → streak计算 → 影响吉祥物状态
- 所有数据本地存储，离线可用

## 非目标（MVP范围内不做）
- 云同步 / 多端同步
- 用户登录 / 账号体系
- 社区 / 排行榜
- AI智能分析
- 第三方内容聚合（爬虫）

## 交付形态
- **Web (PWA)**：主交付形式，浏览器直接打开
- **桌面端 (Tauri)**：exe安装包，系统通知+快捷键
- **移动端 (Capacitor)**：APK安装包，推送通知

一套前端代码，三端复用。
