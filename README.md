# 团子上岸小助手

Q版卡通风格的拟真桌面工作台，专注服务公务员考试备考人群。

## 功能模块

- **专注时刻** — 番茄钟 + 白噪音 + 专注统计
- **知识卡卡** — SRS间隔重复记忆卡片
- **今日计划** — 学习看板 + streak打卡
- **题题大作战** — 刷题练习 + 错题本
- **新闻早报** — 每日时政速递

## 开发

```bash
npm install
npm run dev
```

## 桌面端构建

```bash
npm run tauri build
```

## 技术栈

React 18 + TypeScript + Vite + Zustand + TailwindCSS + Framer Motion
